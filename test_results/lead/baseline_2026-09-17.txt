KEY TEST LEARNINGS
1. add_dataset edge contract: source/target must be integer node ids matching the `concepts`
   value namespace (as graph/demo_graph_data.py does). String labels silently produce no
   subgraph edges -> empty walk -> source-node-only answers.
2. add_dataset WITHOUT embeddings (attach to store._embeddings afterward) to avoid the 0.92
   label-merge dedup collapsing distinct concepts (e.g., animal merged into dog).
3. SQLiteGraphStore(db_path=X) loads existing file if present; rebuilding onto the same path
   appends stale contents. Always start from a deleted/clean file when regenerating.
4. No pipeline code defects exposed in this run. Parity between DictGraphStore (demo) and
   SQLiteGraphStore (toy via --db) is consistent: identical chains/answers on the 3 questions.
