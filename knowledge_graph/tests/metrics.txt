=======================================================================
All core GraphStore operations perform well within target thresholds
on the toy dataset. Key observations:

1. get_neighbors (0.02ms) — Extremely fast; edge indexing via
   source/target dictionaries provides O(1) lookup.

2. get_subgraph_activated (36.25ms) — BFS traversal with activation
   gating; well under 100ms target for a 16-node graph.

3. Similarity Search (52.40ms) — Full-scan cosine similarity over
   16 nodes with int8 dequantization; scales linearly with node count.
   Within 200ms target for the toy dataset.
